## 💻 Projetos em Destaque



### 1. ⚙️ Módulo de gestão de pedidos e fornecedores para mini ERP 

> **Descrição:** Mini ERP desenvolvido para estudos de Java e Spring Boot, com foco na construção de uma API REST para gerenciamento de pedidos e controle de estoque. O projeto aplica boas práticas de desenvolvimento, arquitetura em camadas, validações de regras de negócio, persistência de dados, tratamento de exceções e testes automatizados.



- **Tecnologias:** Java, Spring Boot, Spring Data JPA, PostgreSQL, Jackson.

- **Destaques de Engenharia:**

&#x20; - Implementação de DTOs e mapeamento limpo de entidades.

&#x20; - Tratamento centralizado de exceções (`@ControllerAdvice`).

&#x20; - Integração e consumo de APIs externas de forma assíncrona/performática.
